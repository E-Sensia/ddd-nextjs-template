# Local wiki — repo-specific knowledge

This is the living layer of the repo wiki: knowledge specific to this repo,
maintained by agents (and humans) as work happens — module maps, digested
ADRs, gotchas, archived answers to recurring questions.

Ground rules:

- One topic per note.
- **Cite, never restate**: reference `wiki/standard/` (the authoritative
  architecture standard, mirrored from the KB) and the code. If a note starts
  restating the standard, link to it instead.
- Never edit `wiki/standard/` — change the KB, then `make wiki-sync`.
